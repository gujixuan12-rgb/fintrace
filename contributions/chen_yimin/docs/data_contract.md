# FinTrace数据合同

## 事前输入

每个财务数据点至少包含：

- `value`：十进制字符串
- `unit`：元、万元或亿元
- `scope`：合并、母公司、归母等明确口径
- `source_id`：来源登记编号
- `page`：证据页码

来源登记至少包含来源类型、文件名、正式发布日期和是否允许进入模型。

## 同行基准

同行阈值输入必须包含指标名、样本年度、预警截止日、指标定义版本、方向、最低样本数和通过筛选的数值。每条被排除记录应标记原因：未来来源、事后来源、口径不一致、定义不一致、缺失值或来源未核验。同行有效样本少于最低门槛时，只输出 `INSUFFICIENT_PEER_SAMPLE`。

## 研报声明

声明包含`claim_id`、声明类型、指标、期间、口径、数值、单位和引用页码。声明类型包括：

- `amount`：金额核验
- `ratio`：比率重新计算
- `citation`：引用页码核验
- `direction`：同比增减方向核验

## 输出

完整输出分为：

- `fact_check`：事实核验问题及修改意见
- `analysis`：确定性特征、结构性信号、证据缺口和核查程序
- `agent_explanation`：面向用户的解释
- `evaluation`：事后标签的案例内方向覆盖

所有输出必须保留“风险线索不构成事实认定”的边界。
