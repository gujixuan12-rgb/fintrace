## 最小演示：启明信息 2023 年报分红金额跨页勾稽

更正前年报印刷页 51：股本 408,548,455 股，每 10 股派息 0.10 元，现金分红金额写为 408,548.46 元。印刷页 223：利润分配总额为 408.55 万元。程序用 Decimal 复算得到 4,085,484.55 元，页 51 披露值与计算值差 3,676,936.09 元；计算值按万元保留两位与页 223 一致。更正公告于 2024-04-23 将金额更正为 4,085,484.55 元；这份公告只用于事后验证，不参与前述检测。

## 项目计划书结构

1. 问题与任务：研报草稿中数值、单位、期间、口径和引用错误如何被稳定识别；解释事前材料可见性。
2. 技术路线：文件识别 → 截止日过滤 → 证据抽取和页码定位 → Python 复算 → 一致性核查 → 大模型解释与修改建议 → 守门与日志。明确当前已实现、待实现两类。
3. 案例与证据：启明信息跨页分红勾稽为正例；选择一个原材料内部自洽的案例作误报对照，不能把事后更正事实反推成事前可检信号。
4. 评测设计：逐条主张标注真值，统计 TP/FP/FN、页码定位正确率、修改建议可执行性；样本少时只报告案例级结果，不宣称泛化准确率。
5. 风险和局限：PDF复杂表格、引用页码错位、来源日期、模型幻觉、同行口径不齐；对应降级和人工复核机制。
6. 协作与里程碑：五人交付接口、真实案例复核、视频冻结日期、答辩准备。
