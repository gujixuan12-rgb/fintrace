# FinTrace评测方案

## 数据划分

- 开发集：美晨生态，用于建立数据合同、计算规则和错误处理。
- 盲测集：至少一个未参与规则设计的独立案例。
- 扩展测试集：逐步增加不同行业和不同错误类型案例。

## 评测维度

### 事实核验

- 数字冲突识别率
- 单位错误识别率
- 口径缺失识别率
- 引用页码错误识别率
- 无错误声明的误报率

### 风险预警

- 风险维度覆盖率
- 无关信号数量
- 证据可追溯率
- 核查建议可执行性
- 事后信息泄露次数，目标必须为0

### Agent解释

- 是否新增输入中不存在的数字或事实
- 是否把风险线索误写成确认结论
- 是否完整披露证据缺口
- JSON结构合规率

## 当前可报告结果

美晨生态只能作为案例展示。当前的案例内方向覆盖不能替代准确率、召回率或样本外性能。获得第二个独立案例后，才能开始盲测。
