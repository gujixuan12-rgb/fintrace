# 同行来源准入补强

当前副本在 Codex 可写本地目录，桌面原项目未修改。

同行记录须提供来源文件、页码、发布日期、核验状态、公司、年份、指标定义、单位和业务组。程序排除未来材料、更正后材料、来源缺失、重复公司和目标公司自身，并记录原因。停止接受旧版裸数值接口。

10家只是项目可配置最低数量，不是统计可靠性的保证。不可为凑数量加入不可比公司。来源核验仍由人工负责，verified=true 不代表程序已经阅读原始PDF。MAD为0时Z值不可计算，不代表没有风险。
