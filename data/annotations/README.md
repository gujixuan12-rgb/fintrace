# 研报草稿测试样本（annotations）

本目录存放**待核查的研报草稿**及其**真值标注**。两者物理分目录，防止检测流程误读答案。

## 目录约定

    drafts/      待核查的草稿正文 —— 这是检测流程的输入
    evaluation/  逐条真值标注 —— 评测专用，严禁传入检测流程、提示词、检索索引

### QM-DRAFT-2023-001（启明信息 2023 年报点评草稿）

- 数字全部取自启明信息《2023 年年度报告》（2024-04-13 披露，SHA256 `a9f276a9…`）公开披露值。
- **错误由我方主动植入**并逐条标注真值。本样本不是真实券商研报，不得对外发布。
- 判定分布：支持 6 条、矛盾 6 条、证据不足 1 条；错误类型覆盖数值数量级、数值不符、单位、
  统计口径、跨页勾稽、引用页码六类。
- 预测截止日 2024-04-22：官方更正公告（2024-04-23）落在截止日之后，用于检验防泄漏时间截断。
  第 QMD-004 条是核心案例——草稿照抄了原年报第 51 页的错误披露值，判定必须建立在
  「按预案复算 + 第 223 页互证」之上，不得引用更正公告。
- 误报控制负例：QMD-009/010/011/012 均为正确主张，其中 QMD-009/010 存在单位换算
  （万元↔亿元）与四舍五入，QMD-012 的费用方向与业绩方向相反，均不得判为错误。

## 标注要求（写新样本时必须遵守）

1. 每条主张给出 `expected_verdict`（SUPPORTED / CONTRADICTED / INSUFFICIENT）。
2. 判 CONTRADICTED 的必须给出 `error_type` 与 `suggested_fix`。
3. 判 INSUFFICIENT 的不得附正面证据，须写明 `missing_input`——缺什么就说什么，不许编页码。
4. 每条证据给出 `pdf_page` 与去空白后的 `quote`，且必须在对应页上可检索到。
5. 至少保留正确主张作误报控制负例，并在 `false_positive_note` 里写明为什么容易误报。

## 自检

标注自身出错，评测即失效。写完必须跑自检：

    python tools/audit_annotation.py

它会核对每条证据的页码与数字是否真的能在源 PDF 上找到，并检查上述不变量。
