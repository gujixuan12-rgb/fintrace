# 陈丹阳反馈文件审阅与接入结论

审阅文件：`threshold_method (1).xlsx`、`财报更正标注规范与数据表.xlsx`、`文件标签分类.xlsx`、`peer_financial_data.xlsx`。

## 已确认事实

- 同行数据表共有41条公司年度记录：美晨生态6年、7家同行各5年。
- 2020年横截面剔除目标公司后只有7家同行，不能稳定估计P10/P90尾部分位数；系统最低有效样本数暂设为10。
- 美晨生态6年数据明确采用2022年更正后口径，因此不得进入2020年事前预警输入或事前阈值校准。
- 同行表中美晨生态毛利率公式 `O7:O12` 错把营业成本列 `N` 写成 `NC`，Excel重算后会返回空值。
- 41条记录中，经营现金流缺3条、应收账款缺4条、合同资产缺26条、应收坏账准备缺5条、合同资产减值准备缺26条。
- 9条记录的来源说明含同花顺或评级报告，4条含问询函回复；目前未逐条登记发布日期、页码和可用于事前输入的状态。
- 更正标注表共有15条主张：11条 `CONTRADICTED`、4条 `SUPPORTED`，且标注人和复核人均为空。

## 接入决定

1. 阈值方法保留为候选方法，但暂不把该表中的同行数值接入事前模型。
2. 新增同行阈值计算模块：样本数不足时必须输出 `INSUFFICIENT_PEER_SAMPLE`，不得给出伪精确分位数或MAD异常结论。
3. 同行样本进入模型前必须逐行通过四项门槛：同年度、同指标定义、发布日期不晚于预警截止日、来源允许用于事前输入。
4. 更正公告、更正后报告、问询回复和鉴证材料只用于事后标签与评测，不参与事前特征或阈值。
5. `SUPPORTED/CONTRADICTED` 是主张级事实核验标签，不应用来代替文件角色。文件另设 `document_role`，例如原始年报、更正公告、更正后报告、监管材料。

## 需要修正的数据问题

- 将 `O7:O12` 的 `NC` 改为 `N`，并重新计算、检查全部公式。
- 每个数据点补齐来源文件、页码、发布日期、单位、合并/母公司口径、原值/账面价值口径。
- 将“缺口”与已有数值冲突的备注逐条澄清：若来自第三方材料，不能写成“原始年报已取得”。
- 将2020年前后的合同资产指标分开处理；不能把准则变更导致的列报变化直接解释为经营异常。
- 将标注人、复核人补齐，并让复核人独立于标注人。

## 阈值版本规则

- `direction`: 每个指标明确高值风险、低值风险或双尾风险。
- `min_sample_size`: 当前默认10；少于10仅报告样本不足。
- `robust_z`: `abs(x-median)/(1.4826*MAD)`；MAD为0时不输出Z值。
- `percentile_rank`: 只在有效样本达到门槛后输出。
- 所有阈值结果必须携带样本年度、样本数、排除原因和版本号。
