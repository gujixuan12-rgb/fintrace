# FinTrace 事前财务风险预警智能体

FinTrace先核验研报中的数字、单位、期间、统计口径、公式和引用来源，再通过确定性计算识别财务结构异常，最后生成风险假设、证据缺口和建议核查程序。

系统不会仅凭异常信号认定错报、舞弊或违法。更正公告、问询回复和鉴证报告只在风险信号生成后用于评测，禁止进入事前模型输入。

## 系统流程

```text
财报与研报声明
    ↓
来源日期控制与事实核验
    ↓
Decimal确定性计算
    ↓
结构性风险信号
    ↓
规则模板或可选大模型解释
    ↓
事后标签评测
```

## 当前能力

### 事实核验

- 金额与单位换算
- 财务指标口径检查
- 年份与期间检查
- 原文件页码检查
- 比率重新计算
- 增减方向检查

### 确定性特征

1. 经营活动现金流量净额 / 营业收入
2. 经营活动现金流量净额 / 归母净利润
3. 营业收入同比增长率
4. 归母净利润同比增长率
5. 收入与归母净利润增速背离
6. （应收账款 + 合同资产）/ 总资产

### 同行阈值门槛

- 支持中位数、MAD和经验分位位置计算。
- 同年度、同口径且通过时间与来源筛选的同行少于10家时，输出 `INSUFFICIENT_PEER_SAMPLE`，不强行生成阈值。
- 当前收到的同行样本仍含更正后数据、未来年度数据和未完成来源登记的记录，因此尚未启用为事前模型输入。审阅见 `docs/peer_threshold_review.md`。

### 美晨生态开发案例信号

- 经营现金流相对收入由正转负
- 营业收入增长但归母净利润下降
- 经营现金流为负但归母净利润为正

## 一键演示

Windows用户可以双击 `run_demo.bat`。也可以在项目目录运行：

```powershell
$env:PYTHONPATH="src"
python -m fintrace.cli demo --open
```

演示结果写入 `outputs/demo`。默认使用规则模板生成解释，不需要API密钥。

## 运行测试

```powershell
$env:PYTHONPATH="src"
python -m unittest discover -s tests -v
```

## 可选OpenAI解释层

核心计算不依赖大模型。如需使用结构化大模型解释：

1. 安装可选依赖：`pip install -e ".[openai]"`
2. 复制 `.env.example` 中的变量到本地环境，不要提交密钥
3. 运行：`python -m fintrace.cli demo --use-llm --open`

解释层使用Responses API的JSON Schema结构化输出。模型只能解释确定性结果，不能新增数字或把风险线索改写为已确认事实。设计依据见[OpenAI Structured Outputs官方文档](https://developers.openai.com/api/docs/guides/structured-outputs)。

## 接入第二个案例

复制 `cases/_template`，按照相同数据合同准备事前输入、参考台账、研报声明、事后标签和评测映射。第二个案例应作为盲测案例，不能照搬美晨生态的数值或结论。

## 项目结构

- `src/fintrace`：事实核验、计算、来源防穿越、编排、解释和报告代码
- `cases/meichen_2020`：美晨生态开发案例
- `cases/_template`：新案例接入说明
- `schemas`：输入输出JSON Schema
- `tests`：单元测试和端到端测试
- `docs`：系统设计、数据合同、评测方案和团队分工
- `outputs`：演示输出及计算工作簿

## 当前限制

- 目前只有一个完整案例，不能报告准确率、召回率或样本外预测能力。
- 行业连续指标阈值模块已具备样本门槛与MAD计算，但当前同行数据未通过时间和来源质量筛选，正式预警仍只使用符号、方向和结构关系规则。
- 美晨生态原年报的正式交易所披露日期仍需补充核验。
