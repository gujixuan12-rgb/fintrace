## 二、核心问题：这些错误，在更正公告发布之前能不能自己发现？

这是决定"事前风险预警"这条路能不能被评测的关键。逐组过完的结论：

| 编号 | 可检出性 | 依据 | 状态 |
|---|---|---|---|
| 02 启明信息 | **强**（纯内部复算） | 同一份年报两处自相矛盾，见下 | 已复算验证 |
| 04 华纬科技 | **强**（单表符号/勾稽异常） | 母公司期末现金为负；漏行差值精确等于差额 | 已复算验证 |
| 03 中洲控股 | 中（需跨表取证） | "不存在关联方非经营性占用"是**否定陈述**，须与关联方往来/其他应收款附注交叉 | 推断，未落地验证 |
| 05 派斯林 | 中（需规则 + 量级判断） | 商誉减值预测期起点落在已过去的报告期；长期借款量级与其他行差 2 个数量级；关联交易发生额 13,709 → 137,094 是数字位序错误 | 推断，未落地验证 |
| 01 恒银科技 | 弱（需常识规则） | "半数以上董事无法保证年报真实性"填成"是"。年报内部无任何交叉证据可证伪 | 推断 |

## 三、旗舰案例：02 启明信息（教科书级）

同一份 2023 年年度报告（237 页）内部对不上，两处相隔 172 页：

```
第 51 页  「第四节 公司治理」十、公司利润分配…
    每10股派息数（元）（含税）          0.10
    分配预案的股本基数（股）            408548455
    现金分红金额（元）（含税）          408,548.46      ← 错
    现金分红总额（含其他方式）（元）      408548.455      ← 三位小数，格式即异常
    可分配利润（元）                   24,398,126.94
    现金分红总额占利润分配总额的比例       100%           ← 与上面两个数都对不上

第 223 页 「第十七节 资产负债表日后事项」2、利润分配情况
    …以总股本 408,548,455 股为基数，向全体股东按每 10 股派发现金红利 0.10 元
    （含税），利润分配总额为 408.55 万元                            ← 对
```

复算（`python` + `decimal`，已执行）：

```
408,548,455 股 × 0.10 元 ÷ 10 股 = 4,085,484.55 元
第 51 页披露                       =   408,548.46 元
比值                               = 10.0000 倍
4,085,484.55 ÷ 10 四舍五入到分      =   408,548.46    ← 错误来源：小数点错一位
408.55 万元 = 4,085,500 元，与复算值差 15.45 元（万元四舍五入的正常误差）
```

官方更正公告（2024-04-23，公告编号 2024-012）确认：现金分红金额更正为
4,085,484.55 元，现金分红总额更正为 4,085,484.55 元，股本基数补上千分位。

**为什么这个案例好：**

1. 纯内部矛盾，不需要任何外部数据，也不需要预测。
2. 两处相距 172 页 —— 人工复核几乎不可能发现，脚本一跑就出来。这就是"AI 做核查"的价值主张。
3. 有官方更正公告当 ground truth，可以算命中/误报。
4. 还有两个附带信号（金额三位小数、100% 占比与可分配利润对不上），可用于演示"多信号叠加提高置信度"。
5. 页码、原文、公式、复算值全部可回溯 —— 正好对应官方的"来源可核验、过程可追溯、结果可复现"。

## 四、第二案例：04 华纬科技（符号异常 + 漏行）

母公司现金流量表，更正前：

```
三、筹资活动产生的现金流量：
    吸收投资收到的现金                        844,087,374.40     ← 这一列是 2023 年度
    收到其他与筹资活动有关的现金                  4,244,944.00
    筹资活动现金流入小计                        4,244,944.00
    …（缺"取得借款收到的现金"一整行）
    筹资活动现金流出小计                       59,038,067.32
    筹资活动产生的现金流量净额                 -54,793,123.32
五、现金及现金等价物净增加额                 -460,363,854.54
    加：期初现金及现金等价物余额                399,301,364.46
六、期末现金及现金等价物余额                  -61,062,490.08     ← 负数
```

复算（已执行）：

```
更正后：4,244,944.00 + 105,402,066.89 = 109,647,010.89   ← 与公告一致
更正后：109,647,010.89 - 59,038,067.32 = 50,608,943.57   ← 与公告一致
更正前：-460,363,854.54 + 399,301,364.46 = -61,062,490.08
更正前后净增加额之差 = 105,402,066.89 = 正好是被漏掉的那一行
```

两个可检信号：
- **符号异常**：母公司期末现金及现金等价物余额为负 —— 现金不可能为负，单表内即可判定。
- **跨表勾稽**：合并报表与母公司报表的筹资活动流入对不上，差额精确等于缺失行的金额。

## 五、必须同时记住的边界

1. **这 6 组是"信息披露差错"，不是"财务舞弊"。** 全部 6 份更正公告都写明
   "不影响报告期财务状况和经营成果"。所以叙事不能写成"预警财务造假 / 预测爆雷"，
   否则评委一句话就能问穿。
2. **01 和 06 从"材料内部核查"角度不可检**（06 已复算否定）。如果评测集包含它们，
   正确行为是**不报**，而不是硬凑一个信号 —— 这正好可以拿来做"误报控制"的演示。
3. 03 / 05 的可检性是**推断**，尚未实际落地验证。若要写进计划书的量化指标，
   必须先真跑一遍再写。
4. 材料版权：齐飞扬在 `案例索引.md` 里自己写明"对外展示时建议只展示必要摘录、页码
   和官方来源链接，不要将第三方券商研报全文混入公开数据包"。计划书和视频里引用时遵守这一条。

## 六、对设计的影响

- `calculators` 需要能表达"**跨页/跨表取两个数做一致性判断**"，不只是算比率。
  现有 `ratios.py` 只有比率公式，需要补一类 `consistency_check`。
- 现有的三条异常规则（收现比 / 应收增速 / 毛利率波动）**对不上这 6 组案例**。
  它们是"财务报表异常信号"，而案例要的是"**披露一致性核查**"。规则库需要重做。
- 时间过滤仍有用，但用法变了：不是"只用截止日前材料预测"，而是
  "**把截止日设在更正公告前一天，只用改错前年报**"，作为可复现的评测协议。
